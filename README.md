# 美团优惠券投放优化分析

基于 2023 年 1–6 月的订单、领券与访问数据，用 DuckDB SQL 整理订单和券单关系，通过 Power BI 展示经营表现，并按业务线、时机、人群和券规则给出投放建议。

## 分析成果与投放建议

| 分析方向 | 数据发现 | 投放建议 |
| --- | --- | --- |
| 经营大盘与业务线 | 按订单号归并后共 973,363 笔订单。D 线贡献 74.66% 的实付成交额。C 线的实付成交额份额为 2.04%，记录减免份额为 11.09%。 | D 线优先完善投放规则。各业务线参考自身客单价设门槛。C 线暂缓加量，先核实减免来源和承担方。 |
| 商户用券 | 在可识别商户中，有券记录订单数前 10 家的有券订单份额为 0.65%，全部订单份额为 0.59%，两项份额接近。 | 商户先沿用业务线规则。在订单量相近的商户中，重点核查有券订单占比偏高者的减免负担。 |
| 投放与领券时机 | 普通周末日均支付人数比普通工作日高 12.66%。非春节节假日整体接近同月周末。可核验的用券关联支付中，75.01% 发生在领券当天。 | 周末和非春节节假日可参考相近的支付规模安排触达，春节单独排期。领券当天展示使用条件和下单入口。 |
| 券门槛与首次支付 | 低门槛券的历史核销率最高，为 11.49%，每百张可归属记录减免也最高。基线未支付用户中，其他未支付组的低门槛核销率为 6.23%，常访问组为 3.24%。 | 常访问组回访时先展示已有可用券。两组均回访且没有同类有效券时，新增低门槛券优先给其他未支付组，并设置发券上限。 |
| 促成第二单 | 在 7,243 名样本内首单用户中，589 人在首单后第 4–7 天才下第二单。首单当天领取并用于第二单的 23 张券型 1 中门槛券中，17 张集中在两种 D 线 7 天券。第二单当天领用的 57 张券型 1 低门槛券也都用在 D 线。 | D 线可考虑首单当天发 7 天中门槛券，用户回访且尚未再买时先展示已有券，再考虑低门槛券。A、B、C 线的规则需结合各自的订单和用券记录另定。 |

投放建议来自历史订单和用券表现，发券实际能新增多少支付和复购仍待验证。
